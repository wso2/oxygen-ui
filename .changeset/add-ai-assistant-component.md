Add enterprise `AIAssistant` component suite for WSO2 cloud consoles and developer portals:
- Support for `drawer`, `floating`, and `inline` display modes
- Compound component architecture (`Header`, `Messages`, `Message`, `Thought`, `Suggestions`, `PromptInput`, `Trigger`)
- Collapsible chain-of-thought ("Thinking...") reasoning disclosures
- Markdown-aware code block rendering with Prism syntax highlighting and copy-to-clipboard button
- Interactive suggestions chips and file/context attachment badges
- Multi-model switching menu with provider badges
- WCAG 2.1 AA compliant live announcements (`role="status"`, `aria-live="polite"`) and keyboard shortcuts

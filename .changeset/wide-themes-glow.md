Add WSO2WebTheme, the WSO2 Web Design System theme with light and dark colour schemes

Built from the current wso2.com sign-in and console designs. A sibling of `WSO2Theme`
rather than a replacement: `WSO2Theme` keeps the product tangerine and cyan pairing,
while `WSO2WebTheme` carries the web system's deep indigo (#02074B) type colour and
orange-red (#D32F00) action colour.
